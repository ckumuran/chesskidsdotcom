WALL-E is a wearable spatial perception system that explores virtual positioning through a camera-equipped smart-glasses platform. Inspired by systems such as Adruil Eagle Eye, the project uses a forward-facing vision sensor to perceive the user's environment and investigate how visual information can be transformed into a virtual positional representation of physical space. Rather than relying solely on conventional GPS or dedicated positioning hardware, WALL-E explores the possibility of establishing spatial awareness directly from what the user sees, creating a foundation for applications involving navigation, augmented reality, environmental understanding, and human–machine interaction. The project combines wearable hardware, computer vision, spatial reasoning, and virtual positioning into a compact prototype designed to give a machine a sense of where it is and what surrounds it.
